# Changelog

## 0.1.1

- Windows Credential Manager for GitHub/API tokens.
- GitHub workspace panel: unread notifications, assigned issues/PRs and review requests.
- Custom API widget fetched through Rust (no CORS), with configurable value/label paths.
- Signed auto-update via GitHub Releases (check/install and automatic mode).
- Stable runtime copy in `%LOCALAPPDATA%\Programs\Leme` and a release workflow.

## 0.1.0

- Rebranded to Leme.
- Compact hub anchored above the Windows taskbar (native bar untouched).
- Now Playing via SMTC with artwork and transport controls.
- GitHub contributions, daily checklist, themes and opacity.
- Tray icon, autostart, drag anchoring and fullscreen options.
